# Slide 5: Entity Relationship Diagram (ERD)

## Purpose
Visualize the complex relationships between People, Gear, and Events.

## Visual Layout
*   **Layout:** Network Graph / Hub & Spoke.
*   **Style:** Minimalist Database Architecture.

## Key Elements
1.  **Central Hub:** "Transaction" (The binding entity).
2.  **Spoke 1:** "User" (Who took it?).
3.  **Spoke 2:** "Shoot" (Where is it going?).
4.  **Spoke 3:** "Inventory Items" (What is it?).
5.  **Status Flow:** Indicator showing "Open -> Closed".

## Labels / Callouts
*   **Link User-Transaction:** "Responsibility"
*   **Link Shoot-Transaction:** "Cost Allocation"
*   **Link Item-Transaction:** "Chain of Custody"
